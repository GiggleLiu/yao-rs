# Examples

Each example explains an experiment, shows its circuit, and walks through the
result. Start with [your first circuit](../getting-started.md) if you are new to the CLI.

| Example | What you learn | Interface |
|---|---|---|
| [Entangled states](entangled-states.md) | Prepare and measure Bell and GHZ states | CLI |
| [Quantum Fourier transform](qft.md) | Encode amplitudes as phases | CLI |
| [Phase estimation](phase-estimation.md) | Read an eigenphase into an ancilla register | CLI |
| [Ancilla protocols](ancilla-protocols.md) | Estimate expectations and overlaps with Hadamard and swap tests | CLI |
| [Bernstein–Vazirani](bernstein-vazirani.md) | Recover a hidden bit string with one oracle query | CLI |
| [Grover search](grover-search.md) | Amplify the probability of a marked state | CLI |
| [QAOA for MaxCut](qaoa-maxcut.md) | Evaluate a variational circuit with fixed parameters | CLI |
| [Quantum circuit Born machine](qcbm.md) | Sample a parameterized probability model | CLI |
| [Variational quantum eigensolver](vqe.md) | Minimize an energy using circuit gradients | Rust |

Circuit downloads and result plots live on their respective example pages.
